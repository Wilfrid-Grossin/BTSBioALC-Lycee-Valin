Une démarche de commun numérique

Ces principes s'appliquent aux applis publiées sur la Forge (partie 1).

Ouvertes et réutilisables

Le code source est consultable sur la Forge. Chacun peut utiliser, partager et adapter les applis dans un cadre non commercial.

Hébergement public

Les applis sont hébergées sur la Forge des communs numériques éducatifs, service de l'Éducation nationale.

Protection des données

Tout se passe dans le navigateur : aucune donnée d'élève n'est transmise à un serveur.

Conçues en classe

Développées et éprouvées avec les étudiants, interfaces disponibles en français, anglais, espagnol et allemand.
